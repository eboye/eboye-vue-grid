# vue-grid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@nocopypaste/vue-grid`, a CSS-Grid based Vue 3 data grid with a renderer registry for 3rd-party addons, CSS-token theming, sub-grids, selection, column config, pagination and virtualisation, plus a boilerplate renderer addon and a playground.

**Architecture:** Pure, framework-free logic lives in `src/core/*` (unit-tested with Vitest). `VGrid.vue` owns state (v-model props with internal fallbacks) and provides an internal context consumed by the recursive `VGridRows.vue`, `VGridHeader.vue` and `VGridCell.vue`. Renderers are resolved through a registry (column component → local → plugin → built-ins). All CSS is plain, in `@layer vue-grid`, driven by `--vg-*` tokens.

**Tech Stack:** Vue 3.5, TypeScript 6 (strict), Vite 8 library mode, vue-tsc 3 for `.d.ts`, Vitest 5 + @vue/test-utils + jsdom, Playwright 1.65 (Chromium + Firefox), ESLint 10 flat config + Prettier 3, npm workspaces.

**Spec:** `docs/superpowers/specs/2026-11-21-vue-grid-design.md`

## Global Constraints

- Package names: `@nocopypaste/vue-grid`, `@nocopypaste/vue-grid-renderer-template`; playground is private.
- `vue` is a **peer** dependency `^3.5.0`; the library has **no runtime dependencies**.
- Rows are plain objects; no positional cell arrays.
- Props are never mutated; all row state keyed by `rowKey`.
- All library CSS inside `@layer vue-grid`; addon CSS inside `@layer vue-grid-addons`; every
  visual value comes from a `--vg-*` custom property.
- No `innerHTML`/`v-html`/`document.write` anywhere.
- No `window`/`document` access at module import time.
- UI behaviour is verified in a real browser (Playwright, Chromium + Firefox) — jsdom tests do not count as UI verification.
- Never use shell heredocs to create files.

### Task 2: Core logic (value, columns, sort, selection, virtual, pagination, storage)

**Files:** `src/types.ts`, `src/core/*.ts`, `test/core.*.spec.ts`.

**Interfaces (produces):**

```ts
type RowKey = string | number
interface SortState { key: string; dir: 'asc' | 'desc' }
interface ColumnState { order: string[]; hidden: string[] }
getByPath(obj: unknown, path: string): unknown
getCellValue<T>(row: T, col: Pick<ColumnDef<T>,'field'|'value'|'key'>): unknown
resolveRowKey<T>(row: T, rowKey: keyof T | ((r: T) => RowKey)): RowKey
normalizeColumnState(columns: ColumnDef<any>[], state?: Partial<ColumnState> | null): ColumnState
  // drops unknown keys, appends new columns in definition order, hidden defaults from col.hidden
visibleColumns<T>(columns: ColumnDef<T>[], state: ColumnState): ColumnDef<T>[]
  // ordered, hidden removed, pinned-left first, pinned-right last (stable within group)
moveColumn(state: ColumnState, from: string, to: string, columns): ColumnState  // respects pin group
gridTemplate(cols: {width?: string; minWidth?: string}[]): string  // minmax(minWidth, width)
nextSort(current: SortState | null | undefined, key: string): SortState | null // asc → desc → null
sortRows<T>(rows: T[], sort, column, getValue): T[]  // stable, nulls last, numbers/dates/strings (localeCompare numeric)
collectKeys<T>(rows, getKey, getChildren): RowKey[]   // pre-order, includes known descendants
toggleRowSelection(selected: Set<RowKey>, key, descendants: RowKey[], cascade: boolean): Set<RowKey>
selectionState(keys: RowKey[], selected: Set<RowKey>): 'none' | 'some' | 'all'
computeVirtualWindow({scrollTop, viewportHeight, rowHeight, rowCount, overscan}): {start, end, padTop, padBottom}
pageItems(page, pageCount, siblings = 1): (number | 'ellipsis')[]
localStorageAdapter(key: string): ColumnStateStorage   // { load(): Partial<ColumnState>|null; save(s) }
```
